Consensus path

One proposal. Independent validators.

The browser is only a proof viewer. The authoritative path runs through the open-source operator and the deployed Intelligent Contract.

01 / SOURCERetrieve

Validators independently fetch a canonical Snapshot GraphQL URL or approved HTTPS source.

02 / NORMALIZEAgree

Strict equality locks the proposal identity and normalized content before assessment.

03 / ASSESSReason

A source-grounded non-comparative prompt produces bounded risk fields.

04 / PRESERVEStore

Verdict, score, categories, summary, provenance, and hashes become readable state.
